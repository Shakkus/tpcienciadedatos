# Hive — prueba DROP externa vs. interna

## 1) Tabla externa

`DROP TABLE bronze_viajes;`

Resultado:

```text
No rows affected
```

Verificacion en HDFS:

```text
$ docker compose exec -T hadoop-namenode hdfs dfs -ls /nexo/bronze/m6_viajes
-rw-r--r--   1 hadoop supergroup   41967019 2026-10-13 23:07 /nexo/bronze/m6_viajes/viajes.csv
```

## 2) Tabla interna

`DROP TABLE silver_viajes;`

Resultado:

```text
No rows affected
```

Verificacion en HDFS:

```text
$ docker compose exec -T hadoop-namenode hdfs dfs -test -e /nexo/warehouse/silver_viajes
warehouse silver path missing
```

Conclusión:

- `bronze_viajes` es EXTERNAL, por eso sus datos siguen en HDFS.
- `silver_viajes` es interna, por eso su ubicacion administrada desaparece al hacer DROP.
